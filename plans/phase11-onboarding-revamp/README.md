# Phase 11 — Onboarding Revamp (planning)

Revamp how curiosity onboards a human. Planning phase only — nothing outside this
folder changes.

The technology (research, wiki, dream, heartbeat, JD, goals) is not the problem.
The problem is **human adoption**: people don't know what AI can do for them,
they're afraid it will cost a lot, take long, and never work, and today's surface
gives them parameters instead of clarity.
